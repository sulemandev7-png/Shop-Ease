About ShopEase

A small store with a simple idea.

Fewer products, chosen with care, on a website that stays online even when a server doesn't.

Our story

ShopEase started as a list of everyday things we kept recommending to friends: a good mug, a lamp that doesn't hurt your eyes, a backpack that lasts. Instead of thousands of choices, we keep a short list of products we'd actually buy.

It's also a hands-on cloud project. The store is a plain HTML, CSS and JavaScript site, served by Apache on Amazon EC2 behind an Application Load Balancer.

Behind the scenes

How this page reached you

The journey of one request, step by step.

  1. You open the site

    Your browser connects to the Application Load Balancer's DNS name on port 80.

  2. The load balancer picks a server

    It forwards the request to one healthy EC2 instance in its target group, spreading visitors across Availability Zones.

  3. Health checks keep it safe

    Every few seconds the load balancer requests health.html. A server that doesn't answer 200 OK stops getting traffic.

  4. Apache sends the files

    Apache (httpd) on Amazon Linux serves these pages from /var/www/html.

  5. Your browser does the rest

    JavaScript loads products.json, keeps your cart in localStorage, and reads server-info.json to show which server answered.

Try it yourself

  • Refresh this page a few times and watch the "Served by" badge switch between servers and AZs.
  • Open health.html - that one word "OK" is what the load balancer checks.
  • Stop one EC2 instance: the site stays up and the badge only shows the remaining server.
  • Add items to your cart, then refresh - the cart stays, because it lives in your browser, not on a server.
